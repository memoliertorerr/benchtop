  generated by `scripts/gen-esp32-reg-defaults.ts` from the register headers of ESP-IDF v4.4.7
  as shipped in Arduino-ESP32 2.0.17 (`tools/sdk/esp32/include/soc/esp32/include/soc/*.h`),

  a TypeScript table. Register addresses, field positions, interrupt source numbers and ROM
  symbol addresses used throughout `packages/esp32` come from the same headers and from the ROM
  linker script `esp32.rom.ld` in that SDK.

## Test firmware (`fixtures/firmware/`)

The `.hex`, `.elf` and `.bin` files are compiled by `npm run fixtures` from the sketches in
`fixtures/sketches/` (MIT, part of this project) with the toolchains of the Arduino cores named
in `fixtures/firmware/manifest.json`. Linked into them, under their own licenses:

| Component | Used by | License | Source |
|---|---|---|---|
| Arduino AVR core 1.8.7 (incl. Wire, SPI, EEPROM, SoftwareSerial) | Uno fixtures | LGPL-2.1-or-later | <https://github.com/arduino/ArduinoCore-avr> |
| avr-libc | Uno fixtures | BSD-3-Clause | <https://github.com/avrdudes/avr-libc> |
| LiquidCrystal 1.0.7, Servo 1.3.0, Stepper 1.1.3 | some Uno fixtures | LGPL-2.1-or-later | <https://github.com/arduino-libraries> |
| Adafruit GFX 1.12.4, Adafruit SSD1306 2.5.16 | `ssd1306-adafruit` | BSD | <https://github.com/adafruit> |
| Adafruit BusIO 1.17.4 | `ssd1306-adafruit` | MIT | <https://github.com/adafruit/Adafruit_BusIO> |
| DHT sensor library 1.4.6 | `dht22-adafruit` | MIT | <https://github.com/adafruit/DHT-sensor-library> |
| Adafruit Unified Sensor 1.1.15 | `dht22-adafruit` | Apache-2.0 | <https://github.com/adafruit/Adafruit_Sensor> |
| DHTlib 0.1.37 | `dht22-dhtlib` | MIT | <https://github.com/RobTillaart/DHTlib> |
| Arduino-ESP32 core 2.0.17 | ESP32 fixtures | LGPL-2.1-or-later | <https://github.com/espressif/arduino-esp32/tree/2.0.17> |
| ESP-IDF v4.4.7 libraries (incl. FreeRTOS, MIT; newlib, BSD-style) | ESP32 fixtures | Apache-2.0 and others | <https://github.com/espressif/esp-idf/tree/v4.4.7> |
| GCC runtime (libgcc) | all fixtures | GPL-3.0 with the GCC Runtime Library Exception | <https://gcc.gnu.org/> |

The fixtures exist to test the emulator. The complete source of the parts written for this
project (the sketches) is in `fixtures/sketches/`, the exact core and library versions are in
the manifest, and `npm run fixtures` rebuilds and relinks every image with them; the sources of
the LGPL components are available from the links above.

The decode corpora in `fixtures/xtensa/corpus/` are `xtensa-esp32-elf-objdump` output for this
project's test programs and for the instruction words of the `serial-hello` fixture; the Xtensa
test programs in `fixtures/xtensa/` are this project's own assembly sources (MIT).
